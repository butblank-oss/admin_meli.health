# 맬리 케어센터 채널 어드민

채널관리자용 어드민 화면 11개 + 디자인 시스템의 프로토타입·디자인 소스.

## 바로 보기

| 파일 | 내용 |
|---|---|
| `meli-admin-prototype.html` | 동작하는 프로토타입 (브라우저로 열면 끝) |
| `meli-channel-admin.html` | 아트보드 13장 캔버스 (Claude Design 퍼블리시본) |
| `맬리_어드민_디자인_핸드오프/` | 리디자인 요청용 패키지 (화면 13장 + 프롬프트) |

## 소스

- `ADMIN_DESIGN.md` — 색·타이포·간격·컴포넌트 토큰
- `canvas.json` — 아트보드 배치
- `build.py`, `screens_*.py` — `*.dc.html` 아트보드 생성기
- `*.dc.html` — 아트보드 13장 (화면 11 + 패턴 + 컴포넌트)

## 데이터

화면의 숫자는 2026년 7–8월 실측값, 이름은 전부 마스킹(`김*자`) 상태입니다.
