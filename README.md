# 맬리 케어센터 채널 어드민

치매안심센터 **채널관리자**가 쓰는 운영 콘솔 프로토타입입니다.
업로드된 단일 HTML 프로토타입을 동작은 그대로 둔 채 배포 가능한 구조로 분리했습니다.

**라이브**: https://butblank-oss.github.io/admin_meli.health/

---

## 무엇인가

- 실제 서버 없이 **브라우저 안에서만 도는 프로토타입**입니다. 빌드 도구도, 백엔드도, 외부 CDN도 없습니다.
- 참여자 822명 / 참여 신청 144건 / 챌린지 4건은 시드 기반 난수(`rnd()`)로 매번 **동일하게** 생성됩니다. 새로고침해도 같은 데이터가 나옵니다.
- 화면에서 한 일(승인, 탈퇴, 푸시 예약, 원문 열람)은 메모리에만 남습니다. **새로고침하면 초기화**됩니다.

## 로컬에서 실행

`file://`로 열면 폰트·스크립트가 막히므로 반드시 정적 서버로 띄웁니다.

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

## 구조

```
index.html                  화면 뼈대 + 모달 8개
assets/css/app.css          전체 스타일 (Pretendard @font-face 포함)
assets/fonts/*.woff2        Pretendard 400/500/700 (서브셋)
assets/js/core.js           유틸·공통 컴포넌트·더미 데이터·라우팅
assets/js/views-people.js   오늘 / 참여자 / 참여자 상세
assets/js/views-program.js  활동 현황 / 상담실 / 일정 / 챌린지
assets/js/views-report.js   푸시 / 리포트 / 신청 / 열람 기록 + 초기화
docs/정책-정의서.md          확정된 규칙과 미결 정책 12건
docs/QA-리포트.md            QA 결과와 발견된 불일치
```

`core.js`가 `App` 네임스페이스를 만들고, 뷰 파일 3개가 `App.V`에 화면을 등록한 뒤
마지막 `views-report.js`가 `buildNav()` → `go('today')`로 부팅합니다. **로드 순서가 중요합니다.**

## 원본 대비 바뀐 것

동작·레이아웃·문구는 손대지 않았습니다. 배포에 필요한 것만 바꿨습니다.

| 변경 | 이유 |
|---|---|
| 단일 HTML → CSS/JS/폰트 파일 분리 | 재방문 전송량 196KB → 3.2KB (첫 로드는 동일). 파일 단위 수정도 가능해짐 |
| `<!doctype html>` + `lang="ko"` + `charset` 추가 | 원본은 quirks 모드로 동작. 표준 모드로 전환 후 렌더링 동일함을 확인 |
| favicon 추가 | 원본의 유일한 404 해소 |
| 원문 열람 방어 코드 1줄 | 목록이 다시 그려진 뒤 열람 확정 시 나던 오류 차단 ([QA-리포트](docs/QA-리포트.md) F-1) |
