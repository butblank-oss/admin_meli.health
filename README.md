# 맬리 케어센터 채널 어드민

치매안심센터 **채널관리자**가 쓰는 운영 콘솔 프로토타입입니다.
업로드된 단일 HTML 프로토타입을 화면과 동작은 그대로 둔 채 배포 가능한 구조로 분리했습니다.

용도는 두 가지입니다 — **기관 시연**과 **개발 착수 전 기준 문서**.

## 무엇인가

- 실제 서버 없이 **브라우저 안에서만 도는 프로토타입**입니다. 빌드 도구도, 백엔드도, 외부 CDN도 없습니다.
- 참여자 822명 / 참여 신청 144건 / 챌린지 4건은 시드 기반 난수로 매번 **동일하게** 생성됩니다.
- 화면에서 한 일(승인, 탈퇴, 푸시 예약, 원문 열람)은 메모리에만 남습니다. **새로고침하면 초기화**됩니다.
- **데스크톱 전용**입니다 (`min-width: 1200px`). 기관 PC에서 쓰는 도구라 넓은 화면을 택했습니다.

## 로컬에서 실행

`file://`로 열면 폰트·스크립트가 막히므로 반드시 정적 서버로 띄웁니다.

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

## 구조

```
index.html                  화면 뼈대 + 모달 9개
assets/css/app.css          전체 스타일 (Pretendard @font-face 포함)
assets/fonts/*.woff2        Pretendard 400/500/700
assets/js/core.js           유틸·공통 컴포넌트·더미 데이터·라우팅
assets/js/views-people.js   오늘 / 참여자 / 참여자 상세
assets/js/views-program.js  활동 현황 / 상담실 / 일정 / 챌린지
assets/js/views-report.js   푸시 / 리포트 / 신청 / 열람 기록 + 초기화
vercel.json                 캐시·보안 헤더
```

`core.js`가 `App` 네임스페이스를 만들고, 뷰 파일 3개가 `App.V`에 화면을 등록한 뒤
마지막 `views-report.js`가 `buildNav()` → `go('today')`로 부팅합니다. **로드 순서가 중요합니다.**

### 손댈 때 알아둘 것

- **검사 등급 구간은 `core.js`의 `TESTS` 한 곳에서만 고칩니다.** `활동 현황 → 판정 기준` 탭의
  표는 이 값에서 계산해 그리므로, 표를 따로 고치면 안 됩니다.
- 색을 바꿀 때는 **배경이 밝은지 어두운지**를 먼저 봅니다. 어두운 배경(`#101828`, `.prev`) 위
  텍스트는 밝게 가야 대비가 나옵니다.
- 아이콘만 있는 버튼을 새로 만들면 `aria-label`을 반드시 붙입니다.

## 배포

**주 배포는 Vercel입니다.** 저장소를 연결하면 push마다 자동 배포됩니다.
빌드 설정은 필요 없고 `vercel.json`이 전부 처리합니다 (framework 없음, 루트를 그대로 서빙).

`vercel.json`이 하는 일:
- `assets/`에 1년 immutable 캐시 → 재방문 전송량 203KB → 3.7KB
- `index.html`은 매번 재검증
- CSP, `X-Content-Type-Options`, `Referrer-Policy` 등 보안 헤더

> GitHub Pages 워크플로도 들어 있지만 **수동 실행 전용**입니다.
> (GITHUB_TOKEN 권한으로 Pages를 자동으로 켤 수 없어 자동 실행에서 뺐습니다.
> 쓰려면 Settings → Pages → Source를 "GitHub Actions"로 한 번 바꿔야 합니다.)

## 원본 대비 바뀐 것

화면 구성·문구·더미 데이터는 그대로입니다. 아래만 바꿨습니다.

| 변경 | 이유 |
|---|---|
| 단일 HTML → CSS/JS/폰트 파일 분리 | 재방문 전송량 203KB → 3.7KB. 파일 단위 수정도 가능해짐 |
| `<!doctype html>` + `lang="ko"` + `charset` | 원본은 quirks 모드로 동작. 표준 모드 전환 후 렌더링 동일함 확인 |
| **검사 등급을 표준 척도로 수정** | 판정 기준 탭과 코드가 어긋나 위험군 선별이 틀어질 수 있었음 ([QA F-2](docs/QA-리포트.md)) |
| **웹접근성 대응** | 납품 대상. WCAG 2.1 AA 자동 검사 위반 176건 → **0건** ([QA 3장](docs/QA-리포트.md)) |
| 명도 대비 미달 색 2종 조정 | `#98A2B3`→`#69707C`, `#3E9E78`→`#317D5F`. 색상·채도는 유지 |
| 원문 열람 방어 코드 1줄 | 목록이 다시 그려진 뒤 열람 확정 시 나던 오류 차단 ([QA F-1](docs/QA-리포트.md)) |
| favicon 추가 | 원본의 유일한 404 해소 |
