### 한 일

**명도 대비** — 실제로 미달인 색은 두 개뿐이었습니다.

| 색 | 용도 | 변경 | 대비 |
|---|---|---|---|
| `#98A2B3` | 흐린 본문·설명 텍스트 | → `#69707C` | 2.57 → **4.99** |
| `#3E9E78` | 선택된 칩의 숫자 | → `#317D5F` | 3.01 → **4.54** |
| `#98A2B3` | 어두운 배경 위 텍스트 | → `#A9B2C0` | (더 밝게) **8.3** |

색상·채도는 그대로 두고 명도만 조절해 **위계와 인상을 유지**했습니다.
점 배경(`.mdot`) 등 텍스트가 아닌 용도의 `#98A2B3`은 건드리지 않았습니다.
어두운 배경(`#101828`) 위 텍스트는 반대로 **더 밝게** 해야 해서 따로 처리했습니다.

**키보드** — 원본은 포커스 표시가 아예 없어 키보드만으로는 현재 위치를 알 수 없었습니다.

- `:focus-visible` 표시 추가 (어두운 상단 바는 밝은 색으로 분리)
- 커스텀 체크박스(`<span>`)에 `role="checkbox"` + 스페이스/엔터
- 정렬 헤더에 `role="button"` + 엔터/스페이스 + `aria-sort`
- 탭에 `role="tab"` + 좌우 화살표·Home·End 이동
- 사이드바 메뉴에 엔터/스페이스
- 모달: 열 때 첫 입력칸으로 포커스, **Tab이 바깥으로 새지 않게 가둠**, 닫으면 원래 자리로 복귀

**스크린리더**

- `<main>` / `<nav aria-label>` / `role="banner"` 랜드마크, `본문 바로가기` 링크
- 화면 제목을 `<div>` → `<h1>`, 카드 제목을 `<h2>`
- 화면 전환 시 제목으로 포커스 이동 + `document.title` 갱신 (테두리는 안 보이게)
- 아이콘 전용 버튼 전부에 이름 부여 (페이지 이동, 월 이동, 닫기, 검색 지우기, 필터 제거)
- 모든 폼 컨트롤을 `<label for>` 또는 `aria-label`로 연결
- 토스트를 `role="status"` / `role="alert"`로 읽히게
- 잠긴 탈퇴 버튼에 `aria-disabled` + 잠긴 이유 안내
- `prefers-reduced-motion` 대응

## 4. 개별 발견 사항

### F-1. 원문 열람 중 목록이 다시 그려지면 오류 — 수정함

열람 모달이 열린 상태에서 목록이 재렌더되면 대상 행이 DOM에서 떨어져 나가고,
확인 시 `Cannot read properties of null (reading 'p')`로 스크립트가 죽었습니다.

대상 행이 살아있지 않으면 모달을 닫고 안내를 띄우도록 방어 코드를 넣었습니다.
30초 자동 재마스킹 타이머가 떨어진 노드를 붙들고 있어 손대는 편이 안전합니다.

### F-2. 판정 기준표 ↔ 실제 등급 계산 불일치 — 수정함

작업 전에는 `활동 현황 → 판정 기준` 탭의 표와 실제 등급 코드가 어긋나 있었습니다.
**표준 척도가 맞다**는 결정에 따라 코드를 표준에 맞췄습니다.

| 검사 | 작업 전 코드 | 작업 후 |
|---|---|---|
| GDS-SF (15문항) | 0–5 / 6–9 / 10+ | 그대로 (이미 표준) |
| ISI-K (7문항) | 15 이상을 한 등급으로 뭉갬 | **0–7 / 8–14 / 15–21 / 22–28** |
| PSS (10문항) | 만점 30, 17 이상을 뭉갬 | **만점 40**, 0–13 / 14–16 / 17–18 / 19–40 |
| SMCQ (14문항) | 표에 없었음 | **표에 추가** (0–5 / 6–14) |

그리고 재발을 막았습니다. **판정 기준 표를 손으로 적지 않고 실제 등급 함수에서 뽑아 그립니다.**
표만 고치고 판정은 그대로인 상황이 구조적으로 생길 수 없습니다.

> 위험군 자동 선별이 이 등급을 그대로 씁니다. 기준이 틀리면 연락해야 할 어르신이 목록에서 빠집니다.

### F-3. 새 열람 기록이 목록 아래로 묻힘 — 유지

`addAudit()`이 날짜는 `2026-08-21`로 고정하고 시각만 브라우저 현재 시각을 씁니다.
새벽에 조작하면 기존 시드 데이터보다 아래로 정렬됩니다. 기록 자체는 정상 적재됩니다.

실서비스에서 **서버 시각**을 쓰면 사라지는 문제라 프로토타입에서는 손대지 않았습니다.

### F-4. 모바일 가로 스크롤 — 데스크톱 전용으로 확정

기관 PC에서 쓰는 도구라 넓은 화면을 택했습니다.
`min-width: 1200px`을 명시해, 창을 줄이면 레이아웃이 깨지는 대신 **가로 스크롤로 원형을 유지**합니다.

### F-6. 더미 데이터 앞뒤 안 맞음 — 유지

시드 난수라 개별 참여자 안에서 값이 안 맞는 경우가 있습니다
(예: `연속 출석 1일`인데 7월 출석 챌린지 `18/15일 성공`).
실데이터로 바꾸면 사라집니다. 시연 대응은 [시연 시나리오](시연-시나리오.md)의 질문 표에 넣어뒀습니다.

### F-7. 새로고침 시 조작 결과 소실 — 사양

서버가 없으니 당연한 동작입니다. 시연 자리에서 새로고침하지 않도록 시나리오에 적어뒀습니다.

### F-8. 페이저 현재 페이지 강조 깨짐 — 수정함 (작업 중 발생)

접근성 작업에서 `aria-current="true"` → `"page"`(표준값)로 바꿨는데
CSS 선택자가 `[aria-current="true"]`로 남아 현재 페이지 강조가 사라졌습니다.
`[aria-current]`로 고쳐 복구했습니다.

> 같은 작업에서 정규식 치환 실수로 모달 4개의 `class`가 깨지고 `id`가 중복된 적도 있습니다
> (`$('#wo-t')`가 null이 될 수 있었음). 발견 즉시 복구했고, 동적 제목 모달 3종이
> 실제로 제목·본문을 채우는지 자동 검사에 추가했습니다.

## 5. 성능

실측값입니다 (gzip 적용 후 기준).

| 항목 | 원본 | 현재 |
|---|---|---|
| 파일 크기 (raw) | 350KB | 311KB |
| **첫 로드 전송량** | 196KB | 203KB — **사실상 동일** |
| **재방문 전송량** | 196KB (매번 전부) | **3.7KB** (HTML만, 나머지 캐시) |
| 외부 의존성 | 없음 | 없음 (동일) |

첫 로드는 나아지지 않았습니다. 원본의 base64 폰트가 gzip으로 대부분 회수되기 때문입니다.
실제 이득은 **재방문**에 있습니다. `vercel.json`에서 `assets/`에 1년 immutable 캐시를 걸어
폰트 150KB와 JS·CSS가 재사용됩니다. 매일 여는 채널관리자에게 체감되는 차이입니다.
