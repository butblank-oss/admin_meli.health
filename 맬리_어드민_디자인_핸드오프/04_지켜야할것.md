# 바꾸면 안 되는 것

디자인 자유도와 무관하게 고정입니다. 이유를 함께 적었으니 판단이 필요하면 참고하세요.

## 법적 요구

| 항목 | 왜 |
|---|---|
| **이름·연락처 기본 마스킹** (홍*동 / 010-****-1234) | 건강정보는 민감정보. 매달 보건소에 제출하는 관리·감독 점검표에 항목이 있음 |
| **원문 열람 시 사유 입력 필수** | 열람 기록 2년 보관 의무 |
| **원문이 보이는 동안 그 행을 주의색으로** | 어깨너머 노출 방지 |
| **열람 기록 화면** | 점검표 "접속기록 보관" 증빙으로 그대로 제출 |
| 명도 대비 4.5:1 이상 | 공공기관 웹접근성 |
| 색만으로 정보 전달 금지 | 상태는 점 + 글자를 함께 |

## 실제 시스템과 맞물린 것

| 항목 | 왜 |
|---|---|
| **PIN 컬럼** | 서버의 `vocNumber`. 전화 응대 시 본인 확인용 조회번호 |
| **N 컬럼** | 서버의 `todayActivityCount`. 오늘 수행한 활동 수 |
| **상태 4종** — 참여 중 / 중도포기 / 만료 / 회원탈퇴 | 서버가 쓰는 값 그대로 |
| **달력 일요일 시작** (일월화수목금토) | 현행 어드민이 이렇게 되어 있어 바꾸면 혼동 |
| **활동 4분류** — 두뇌훈련 / 운동 / 마음다루기 / 검사측정 | 서버 카테고리 |
| **운동은 루틴 아래 동작별 기록** | 이 제품의 차별점. 다른 앱은 "운동 완료 100%"로 끝나는데 여기는 "고양이 자세로 어깨 늘리기, 왼쪽 100%"까지 남음 |

## 권한 구조

채널관리자(주무관)는 **프로그램 일정과 챌린지를 수정할 수 없습니다.**
막기만 하면 B2B에서 클레임이 되므로, 읽기 전용 화면에는 **반드시 변경 요청 경로**를 함께 두세요.

상담실은 **그 방의 담당자로 지정된 사람만 답변**할 수 있습니다.
담당이 아닌 방에서는 입력창 자리에 "원메딕스 운영팀이 담당하고 있어 답변할 수 없어요 + 담당 가져오기"가 들어갑니다.
이건 현재 시스템의 실제 제약이라 디자인으로 숨기면 안 됩니다.

## 밀도

**표 행 높이 52px는 바닥값입니다.** 늘리지도 줄이지도 마세요.
12열 × 20행이 한 화면(1440×900)에 들어와야 하고, 이게 주무관이 822명 명단을 훑는 속도를 직접 결정합니다.

"답답하다"는 느낌이 들면 **표 행이 아니라 섹션 간격**을 늘리세요.

## 색 규칙

| 규칙 | 왜 |
|---|---|
| 키컬러 `#13BD7E`를 **글자색으로 쓰지 않기** | 흰 배경 대비 2.44:1로 기준 미달. 채움색 전용 |
| 브랜드 채움 위 글자는 `#043528` | 5.57:1 |
| 링크·강조 텍스트는 `#077A50` | 5.37:1 |
| **중립색에 초록빛 금지** | 초록 강조색 옆에 초록빛 회색을 깔면 전체가 탁해져 낡아 보임. 파랑 쪽으로 살짝 기운 회색을 쓸 것 |
| **"참여 중"은 회색** | 822명 중 802명의 기본 상태. 초록으로 칠하면 화면의 90%가 초록이 되고 진짜 봐야 할 20명이 묻힘 |
| 차트에 상태색 쓰지 않기 | 계열 구분은 브랜드 그린 농도로 |
