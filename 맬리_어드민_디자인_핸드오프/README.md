## 어떻게 쓰나

1. **`00_클로드디자인_프롬프트.md`** 를 엽니다
2. `▼ 여기서부터` ~ `▲ 여기까지` 사이를 그대로 복사
3. Claude Design에 붙여넣고, 아래 파일들을 첨부합니다
