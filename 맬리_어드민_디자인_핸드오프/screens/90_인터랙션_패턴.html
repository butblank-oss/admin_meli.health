인터랙션 패턴

화면마다 다르게 만들면 안 되는 것들. 표를 어떻게 정렬하고, 뭘 선택했다고 알려주고, 실수를 어떻게 되돌리는지 — 관리자 화면에서 사람들이 이미 알고 있는 약속이에요.

01표 정렬

컬럼 제목을 누르면 정렬돼요. 한 번 누르면 오름차순, 다시 누르면 내림차순. 정렬 가능한 컬럼에는 항상 화살표를 흐리게 띄워둬서 “누를 수 있다”를 알려요.

02선택

체크박스는 세 가지 상태가 있어요. 페이지 넘김이 있으면 “이 페이지”와 “조건 전체”를 반드시 나눠야 해요.

선택 안 됨
해제
일부 선택
이 페이지 일부
전체 선택
이 페이지 전부
페이지 넘김이 있을 때 — 2단계 선택 (핵심)
이 페이지 20명 선택
조건에 맞는 184명 전체가 선택됐어요

헤더 체크박스는 보이는 페이지만 선택해요. 184명 전체에 작업하려면 한 번 더 명시적으로 눌러야 해요. 이걸 구분 안 하면 20명만 지우려다 184명을 지우는 사고가 나요.

03검색

입력하면 지우기 버튼이 생기고, 결과가 없으면 무엇으로 찾았는지 되짚어줘요.

04적용된 조건

켜져 있는 필터만 따로 모아 보여주고 하나씩 뗄 수 있게 해요.

적용된 조건은 따로 모아서 하나씩 뗄 수 있게
적용된 조건검색 “정”14일+ 무활동남동구보건소

칩이 여러 줄로 늘어나면 뭐가 켜져 있는지 안 보여요. 켜진 조건만 따로 모아 보여주고, 각각 × 로 뗄 수 있게 해요.

05기간

프리셋을 먼저 주고 직접 지정은 마지막에.

기간은 프리셋 먼저, 직접 지정은 마지막
2026-08-01 ~ 08-21

달력 입력 두 칸만 두면 매번 날짜를 세야 해요. 실제로 쓰는 건 거의 프리셋이에요.

06버튼 상태

누른 뒤 반응이 없으면 사람은 한 번 더 눌러요. 처리 중 상태가 반드시 필요해요.

버튼 상태 — 누른 뒤 아무 반응이 없으면 두 번 누르게 돼요

비활성 버튼에는 왜 못 누르는지를 툴팁으로 붙여요. 예: “참여자를 먼저 선택해주세요”

07결과 알림

작업이 끝나면 무슨 일이 일어났는지 알려주고, 되돌릴 수 있으면 되돌릴 기회를 줘요.

3명에게 메시지를 보냈어요
12건 중 2건이 실패했어요
3명을 탈퇴 처리했어요

되돌릴 수 있는 작업은 확인창 대신 실행 후 되돌리기가 더 빨라요. 일괄 작업이 부분 실패하면 몇 건이 왜 실패했는지 반드시 알려줘야 해요.

08폼 오류와 포커스

오류는 무엇을 어떻게 고칠지 말해줘요. 포커스 링은 키보드 사용자의 유일한 단서예요.

기다리는 동안 빈 화면을 보여주지 않고, 실패했을 때 다시 시도할 길을 줘요.
